# 🏡 Next-Door

**Next-Door** is a full-stack **Airbnb clone** built as part of a **Node.js tutorial project**.  
It demonstrates how to design and implement a modern web application with features inspired by Airbnb, including property listings, user authentication, and booking functionality.

---

## ✨ Features
- 🔐 **User Authentication**: Sign up, log in, and manage accounts securely.
- 🏠 **Property Listings**: Add, edit, and view rental properties with details such as location, price, and amenities.
- 📅 **Booking System**: Users can book available properties and view their reservations.
- 🌍 **Search & Filter**: Find properties by location, price range, and other criteria.
- 📸 **Image Uploads**: Upload property photos to enhance listings.
- ⚡ **Responsive UI**: Built with modern design principles for desktop and mobile.

---

## 🛠️ Tech Stack
- **Backend**: Node.js, Express.js  
- **Database**: MongoDB (with Mongoose ORM)  
- **Frontend**: EJS templates / HTML, CSS, JavaScript  
- **Authentication**: Passport.js / JWT  
- **Hosting**: Local development (can be deployed to platforms like Heroku or Vercel)
